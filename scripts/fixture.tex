% Packages beyond our own house-style template (above) — widened to also warm the cache for the
% single most common family of externally-authored LaTeX resumes people upload (the "Jake's
% Resume" template and its many forks: latexsym/fullpage/marvosym/color/verbatim/fancyhdr/
% babel/tabularx). Doesn't make every possible external .tex compile — that template usually also
% \input{glyphtounicode}, which calls the pdfTeX-only \pdfglyphtounicode primitive the moment it
% loads. Tectonic's engine doesn't implement that primitive at all, so there's no cache-warming
% fix for it, not even caching glyphtounicode.tex itself (tried — it crashes THIS build, not just
% an uploader's). lib/latex.ts strips that at compile time instead. Everything below it isn't.

\usepackage{fullpage}
\usepackage{marvosym}
\usepackage{color}
\usepackage{verbatim}
\usepackage{fancyhdr}

\usepackage{tabularx}
% NOT \usepackage{charter} — that legacy package has no font-shape entry for XeTeX's Unicode (TU)
% encoding, so under Tectonic it doesn't error, it silently substitutes the default font and
% reflows the whole document (confirmed by rendering both and comparing — not a guess). lib/
% latex.ts rewrites \usepackage{charter} to \usepackage{XCharter} at compile time — the actively-
% maintained XeTeX/LuaTeX-native rebuild of the same typeface, real OpenType files. Warmed here
% under its real name so that substitution has something to land on.
\usepackage{XCharter}
